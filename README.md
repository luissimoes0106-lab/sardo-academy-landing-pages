# Landing Page Demo — Sardo Academy

Amostra visual e funcional para lançamentos futuros. Nenhuma captura real de dados está ativa.

## Incluído
- Identidade escura/dourada com layout responsivo
- Nome completo, WhatsApp, e-mail, tipo de negócio, maior dor, estado e cidade
- Lista de municípios carregada da API pública do IBGE
- Validação dos campos e mensagem de teste concluído
- **Não envia nem armazena leads**

## Visualizar
Abra `index.html` no navegador ou publique a pasta raiz em hospedagem estática (Cloudflare Pages ou GitHub Pages). A seleção de cidades precisa de internet para consultar o IBGE.

## Antes de usar para captar leads reais
Configurar backend/webhook seguro para os dados, LGPD/política de privacidade, integrações de UTM, Make/Kommo e testes ponta a ponta. Não publicar credenciais de CRM ou webhooks privados no JavaScript do navegador.
